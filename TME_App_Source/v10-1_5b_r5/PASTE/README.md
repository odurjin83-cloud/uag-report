## Хүлээгдэх үр дүн
- Хадгалалтын хурд **түүхийн мөрийн тооноос хамаарахгүй** (дискэнд бичих хэмжээ тогтмол). Хурдны мөрний "түүх N мөр" нь 3 хоногийн цонх болно.
- Апп нээгдэх: SharePoint-оос 3 хоногийн мөр л татна.
- Тооллого бүрт дахин тооцоологддог 40+ томьёо 3 хоногийн мөрөөр л ажиллана.

## Хязгаар (MVP)
- Төхөөрөмж дээрх **түүх, 8 сарын график, өөрийн тайлан** (ScrHistory, ScrSync, ScrReport1, ScrDashboard) сүүлийн 3 хоногийг л харуулна. Нэгдсэн тайлан (ScrCombined) SharePoint-оос уншдаг тул бүрэн хэвээр.
- Офлайн байхдаа аппыг дахин нээвэл илгээгдсэн мөрүүд `C22H` бичигдсэн хэмжээгээр (≤10 мин хоцрогдолтой) харагдана; сүлжээнд ормогц бүрэн болно. Өгөгдөл алдагдахгүй — SharePoint-д бий.
- 3-аас өөр хоног хэрэгтэй бол `App.OnStart` дахь `Set(varCountWindowDaysV22,2)`-г өөрчилнө.

## Урьдчилсан нөхцөл
SharePoint **InventoryCount** → List settings → Indexed columns: `Created`, `Counter` (сэргээх шүүлт), мөн `CountKeyV27`, `Title`, `LocationCode`.

## Тест (Samsung)
1. Хуучин түүхтэй хэрэглэгчээр (Од) r5-ийг нээх → өмнөх илгээгдээгүй мөрүүд хэвээр, "Локал · N" өмнөхтэй ижил. Сүлжээнд холбогдсоны дараа SharePoint-д давхардалгүй.
2. 20+20 хадгалалт → хурдны мөрний "түүх" ≤ 3 хоногийн мөр, P50/P95 TEST_1-ээс бага эсвэл тэнцүү.
3. Офлайн: 5 тооллого → аппыг бүрэн хааж нээх → 5 мөр "Локал · 5" → сүлжээ → бүгд нэг удаа илгээгдэнэ.
4. Аппыг 2 удаа хааж нээх → `C21` шилжүүлэлт давтагдахгүй (мөр давхардахгүй).
5. Офлайн нээлт → хадгалах товч ажиллана (диск аюулгүй уншигдсан).
